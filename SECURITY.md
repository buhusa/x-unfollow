# Security

## Keep credentials private

`x-unfollow` stores OAuth credentials in `user-data/tokens.json`. The complete
`user-data/` directory is ignored by Git and must never be shared.

Do not post Client Secrets, access tokens, refresh tokens, exported account
data, or screenshots containing them in public issues.

## Report a vulnerability

Please contact the maintainer privately through
[buhussy.xyz](https://buhussy.xyz/) before publishing details of a security
issue.
